Rótulo pequeno que categoriza ou denota status. Não é interativo.

## Variantes

- **Padrão**: borda, sem preenchimento
- **Status aprovado**: verde
- **Status pendente**: amarelo
- **Status rejeitado**: vermelho
- **Destaque**: cor da marca (azul)

## Uso

```html
<span class="br-tag">Categoria</span>
<span class="br-tag approved">Aprovado</span>
<span class="br-tag pending">Pendente</span>
<span class="br-tag rejected">Rejeitado</span>
```

## Regras

- Texto breve — máx. 2 palavras.
- Usar para status, categorias, filtros (leitura).
- Não para ação — use botão.
- `border-radius: rounder-pill`.
