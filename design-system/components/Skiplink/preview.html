Componente Skiplink

O skiplink é um link invisível no topo da página que fica visível quando recebe foco (Tab). Ele permite que usuários de teclado e leitores de tela pulem direto para o conteúdo principal.

Uso

<a href="#main" class="br-skiplink">Ir para o conteúdo principal</a>

Regras

  • Deve ser o primeiro elemento interativo da página (logo após a tag <body>).
  • Fica invisível por padrão, aparece no foco do teclado.
  • href aponta para id="main" (ou o seletor que envolve o conteúdo principal).
  • Texto deve ser descritivo: "Ir para o conteúdo principal", não "Skip".
