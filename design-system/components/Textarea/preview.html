Exemplo

Máximo de 500 caracteres

Regras

  • Sempre `
  • Use `placeholder` para dica, não instrução obrigatória.
  • `rows` define altura inicial (ex: `rows="4"`).
  • `resize: vertical` permite altura flexível; `resize: none` fixa.
  • Espaços e quebras de linha são preservados.
  • Nunca use input comum para texto longo — use textarea.
